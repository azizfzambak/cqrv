## 1. Summary

**What the reviews confirm.** Version 1.1 changed no Lean, Python or JSON file. Its text corrections
are in place, and the seven Lean names it added exist with the stated forms. The `dataPhys`
disclosure is accurate. The Zenodo file of version 1.1 matches the repository PDF.

**What they found.**
- **A regression introduced by version 1.1 (RR2).** The wrapped gadget's emulator threshold was
  changed from 0.857 to 0.875, as a "typo" (`REVIEW_RESPONSE_2.md` #28). 0.857 was right.
- **A calibration gap (RR2).** The approximate-QFT counting bound is vacuous at the sizes of the
  paper. It is the only client of the coherent composition theorem, and the paper did not say so.
- **A README sentence (RR1).** "Strict hierarchy" for the ancilla regimes, which the paper withdrew.
- **A missing DOI (RR2).** The list of versions did not give version 1.1's own DOI.
